# Task 1 -- Data Cleaning with Python

## Overview

This program uses Pandas to clean a sample dataset.

## Operations

-   Checks missing values.
-   Removes duplicate records.
-   Fills missing `Age` and `Salary` values with their column averages.
-   Standardizes the formatting of `Name` and `City`.
-   Displays the cleaned dataset and checks for remaining missing
    values.
-   Saves the cleaned data as `cleaned_dataset.csv`.

## Requirements

-   Python 3
-   Pandas

Install Pandas:

``` bash
pip install pandas
```

## Run the Program

``` bash
python task1_data_cleaning.py
```

You can also run the code in Jupyter Notebook or Google Colab.

## Output

The program creates:

-   `cleaned_dataset.csv`

The output CSV is saved in the current working directory.

## Note

The program uses sample data defined in the Python code. Replace it with
your own dataset when needed.
